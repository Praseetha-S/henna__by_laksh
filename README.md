# Henna by Laksh 🌿

A modern, responsive business website designed and developed for **Henna by Laksh**, a henna artistry business.

## ✨ About the Project

This website was created as a real-world project for my friend's henna business. The main goal was to build a clean, elegant, and user-friendly online presence that showcases the brand, henna services, and artistic work.

The website is designed to provide a smooth browsing experience across desktop, tablet, and mobile devices.

## 🚀 Features

- Responsive design for different screen sizes
- Elegant and modern visual design
- Hero section introducing the brand
- Services showcase
- Henna work / gallery section
- Business information
- Contact and enquiry sections
- Smooth navigation and interactive elements
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 🎨 Design

The website focuses on a minimal, elegant aesthetic inspired by the traditional art of henna while maintaining a modern digital experience.
